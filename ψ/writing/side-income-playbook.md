# Thai AI Side-Income Playbook

> ไอเดียธุรกิจ standalone (ไม่เกี่ยวกับ Ayami Oracle) ที่สร้างจากเครื่องมือกลุ่ม "Strong fit" ในการเช็ค [Tool Stack Audit](https://claude.ai/code/artifact/0e56e04a-ae33-44cc-8443-b7545426e1ca) — คิดคู่กันโดย zcode (GLM) และ agy (Gemini/Claude) แล้วสรุปรวมโดย Ayami
>
> บันทึกเมื่อ 2026-08-25

## วิธีอ่านคู่มือนี้

ทั้ง 6 ไอเดียด้านล่างเรียงตาม **time-to-first-revenue** (เร็วสุดก่อน) แต่ละไอเดียมี: กลุ่มลูกค้า, โมเดลรายได้, tool stack, ขั้นตอน MVP แบบทำตามได้จริง, เวลาที่คาดว่าจะได้ลูกค้าคนแรก, และความเสี่ยงหลัก

ไอเดียที่ **ทั้ง zcode และ agy เสนอแบบเดียวกันโดยไม่ได้นัดกัน** (คนละ process, ไม่เห็นคำตอบของกันและกัน) ถือเป็นสัญญาณว่าน่าจะเป็นช่องว่างตลาดจริง ไม่ใช่แค่ AI คิดมั่ว — จะมาร์คไว้ว่า **"ตรงกันทั้งคู่"**

## 1. Thai Real Estate AI Video Generator

**ตรงกันทั้งคู่** — agy เรียก "Real Estate Listing Video Pack", zcode เรียก "AI Thai Voice-Over for Real Estate"

**เหมาะกับ:** นายหน้าอสังหาฯ, ทีมขายโครงการคอนโด, sales gallery
**คนจ่ายเงิน:** นายหน้าที่โพสต์ขายคอนโด/บ้านบน Facebook แล้วยังใช้รูปนิ่งหรือวิดีโอทำเองคุณภาพต่ำ

**โมเดลรายได้:** ต่อวิดีโอ ฿300–500 (เริ่มต้น) → ขึ้นเป็น ฿500 หลังมีลูกค้า 5 ราย | แพ็กเกจ ฿1,490–3,500/เดือน (10 วิดีโอ) | Agency white-label ฿15,000/เดือน

**Tool stack:** `fal.ai` (แต่งภาพ) → `openrouter.ai`/DeepSeek (เขียนสคริปต์ไทย) → `speechgen.io` (พากย์เสียงไทย) → `creatomate.com`/`shotstack.io` (ต่อภาพ+เสียง+ซับเป็นวิดีโอ 9:16)

**ขั้นตอน MVP:**
1. ต่อ n8n workflow บน Railway: LINE Bot รับรูป 5–8 รูป + ข้อมูล (ราคา, ทำเล, BTS, ตร.ม.)
2. ส่งรูปผ่าน fal.ai ปรับแสง/สีให้ดูโปร
3. DeepSeek เขียนสคริปต์ไทย 30–60 วิ เน้นจุดขาย (ทำเล, ห้อง, ราคา)
4. Speechgen สร้างเสียงพากย์ไทย
5. Creatomate/Shotstack ต่อภาพ+เสียง+ข้อความเป็นวิดีโอแนวตั้ง ส่งกลับทาง LINE ภายใน 2–5 นาที
6. ทำตัวอย่าง 5 คลิปจากประกาศขายจริงใน กลุ่ม FB "ขายคอนโด กรุงเทพ" ไว้เป็นพอร์ต
7. DM นายหน้า 20 คนที่โพสต์วิดีโอคุณภาพต่ำ เสนอทำฟรี 2–3 ห้องแรก
8. ปิดลูกค้าจ่ายเงินคนแรกที่ ฿300/วิดีโอ ราคาทดลอง

**เวลาจนได้ลูกค้าคนแรก:** ~2 สัปดาห์ (เร็วสุดในกลุ่มนี้)
**ความเสี่ยงหลัก:** เสียง TTS ฟังดูเป็นหุ่นยนต์ — ต้องเทสต์เสียงทุกตัวเลือกก่อน ให้คนไทยฟังแล้วถามว่าไหว/ไม่ไหว

## 2. Thai Document / Receipt / Form OCR Service

**ตรงกันทั้งคู่** — agy เสนอ "Tax Invoice OCR LINE Bot", zcode เสนอทั้ง "Legal Document Intelligence" และ "Government Form Auto-Filler" — สามตัวใช้ core stack เดียวกัน ต่างกันแค่ตลาด

**เหมาะกับ:** สำนักงานบัญชี, สำนักงานกฎหมาย, ร้านรับจดทะเบียนรถ, HR บริษัท SME
**คนจ่ายเงิน:** ธุรกิจที่ต้องกรอก/แกะข้อมูลจากเอกสารไทยซ้ำๆ ทุกวัน

**โมเดลรายได้:** Subscription ฿990–3,900/เดือน ตามปริมาณเอกสาร | Enterprise/API ฿9,900–15,000/เดือน | Pay-per-page ฿15–150/หน้า

**Tool stack:** `typhoon-ocr-7b` (อ่านข้อความไทยจากภาพ) → `deepseek.com`/`openrouter.ai` (จัดเป็น JSON structured) → `railway.com` (host)

**ขั้นตอน MVP (เริ่มจาก vertical เดียว — แนะนำใบเสร็จ/ใบกำกับภาษี เพราะ scope เล็กสุด):**
1. Deploy n8n บน Railway ต่อกับ LINE Messaging API webhook
2. ส่งรูปใบเสร็จ/ใบกำกับภาษีเข้า typhoon-ocr-7b (ผ่าน HuggingFace หรือ opentyphoon.ai API)
3. ส่ง raw text เข้า DeepSeek จัดเป็น JSON (เลขผู้เสียภาษี, ชื่อบริษัท, วันที่, ยอดเงิน, VAT 7%, หัก ณ ที่จ่าย 3%)
4. Validate logic: เช็คว่า Subtotal + VAT == Total ถ้าไม่ตรง flag ให้ตรวจมือ
5. ส่งผลลัพธ์กลับเป็น Google Sheet/Excel link ใน LINE ทันที
6. ทัก 10 สำนักงานบัญชีในกลุ่ม FB นักบัญชี เสนอสแกนฟรี 30 ใบ
7. เพิ่ม PromptPay QR (ผ่าน Opn หรือ verify สลิปมือใน n8n) ปลดล็อค subscription
8. เมื่อ vertical แรกนิ่งแล้ว ค่อยขยายไปเอกสารกฎหมาย (สัญญาเช่า, สัญญาจ้าง) หรือฟอร์มราชการ (ภพ.30) — แต่ละฟอร์มใหม่ใช้เวลา map field ~2–3 วัน

**เวลาจนได้ลูกค้าคนแรก:** 2–4 สัปดาห์ (ขึ้นกับ vertical ที่เลือก — ใบเสร็จเร็วสุด, เอกสารกฎหมายช้าสุดแต่ราคาสูงสุด)
**ความเสี่ยงหลัก:** ใบเสร็จเลือนราง/ลายมือทำให้ OCR พลาด — คัดกรองลูกค้าที่มีเอกสารคุณภาพดีก่อน หรือทำ manual-review flag

## 3. Thai Podcast/YouTube → Short Clips Repurposing Service

**ตรงกันทั้งคู่** — zcode เรียก "Podcast-to-Reels Factory", agy เรียก "Content Repurposing Engine"

**เหมาะกับ:** พอดแคสเตอร์ไทย, YouTuber สาระ/ความรู้, coach/guru ที่มี long-form content
**คนจ่ายเงิน:** ครีเอเตอร์ที่มีคอนเทนต์ยาวแต่ไม่มีเวลาตัดคลิปสั้นเอง

**โมเดลรายได้:** ต่อ batch ฿2,500–4,000 (1 episode → 5–8 คลิป) | Retainer รายเดือน ฿1,490–12,000

**Tool stack:** `supadata.ai`/`piapi.ai` (ถอดเสียงเป็น transcript พร้อม timestamp) → `openrouter.ai` (หา segment ไวรัล + เขียน hook ไทย) → `creatomate.com`/`shotstack.io` (render คลิปพร้อมซับ) → `upload-post.com`/`blotato.com` (auto-post)

**ขั้นตอน MVP:**
1. สร้าง Telegram bot ส่วนตัว: ส่งไฟล์เสียง → ได้ตัวอย่างคลิป 3 คลิป (30–60 วิ) พร้อมซับไทย
2. Chain: transcript → DeepSeek หา 3 ช่วงที่ quote ได้ + เขียน hook text → Creatomate render คลิปพร้อม waveform/ซับ
3. Deploy backend บน Railway
4. DM พอดแคสเตอร์ไทย 20 คน เสนอทำฟรี 1 batch แลก testimonial
5. โพสต์ before/after บน Twitter ของตัวเองโชว์ผลงาน
6. ทำ Google Form intake: อัปโหลดเสียง + เลือกสไตล์ (สาระ/ดราม่า/สร้างแรงบันดาลใจ)
7. เก็บเงินลูกค้าจ่ายจริง 3 คนแรกที่ ฿2,000 (ราคาทดลอง) แล้วขึ้นเป็น ฿3,500
8. อัปเซล "hands-free" tier ฿5,000/เดือน — auto-post เข้า IG ลูกค้าผ่าน n8n

**เวลาจนได้ลูกค้าคนแรก:** 2–3 สัปดาห์
**ความเสี่ยงหลัก:** ความแม่นยำถอดเสียงไทยแบบพูดเล่น/สแลง — เสนอแก้ฟรี 1 รอบต่อ batch และตรวจมือ 10 งานแรกเอง

## 4. Thai Crypto/Trading Signal Digest

**ตรงกันทั้งคู่** — zcode เรียก "News Sentiment Arbitrage", agy เรียก "Morning Video Digest for Trading VIP Groups"

**เหมาะกับ:** เทรดเดอร์รายย่อยไทย, แอดมินกลุ่ม VIP สัญญาณเทรด, ชุมชน crypto/forex ไทย
**คนจ่ายเงิน:** คนที่อยากได้สรุปข่าว+สัญญาณตลาดแบบไทยๆ เร็วกว่าแปลข่าวเอง

**โมเดลรายได้:** Freemium (delay 30 นาที ฟรี) → Premium ฿1,500–2,500/เดือน (real-time) | B2B white-label ให้แอดมินกลุ่ม ฿2,900/เดือน/กลุ่ม

**Tool stack:** `newsapi.org`/`firecrawl.dev` (ข่าวการเงินไทย) → `taapi.io` (indicator เสริม) → `openrouter.ai` (วิเคราะห์ sentiment + เขียนสรุปไทย) → `speechgen.io`+`shotstack.io` (ถ้าทำเป็นวิดีโอเช้า) หรือส่งเป็นข้อความ Telegram อย่างเดียวก็ได้ (เร็วกว่า)

**ขั้นตอน MVP:**
1. รวบรวม RSS/URL ข่าวการเงินไทย 15 แหล่ง (Money Channel, SET Trade, Thai PBS Business, Kaohoon)
2. n8n workflow ทุก 15 นาที: Firecrawl ดึงหัวข้อข่าวใหม่ → DeepSeek แยก (บริษัท/เซกเตอร์ที่พูดถึง, sentiment บวก/ลบ/กลาง, เหตุผล 1 ประโยค) → เก็บลง SQLite
3. เสริม taapi.io: ถ้า sentiment ตรงกับสัญญาณ oversold/overbought ทางเทคนิค ให้ mark "HIGH CONVICTION"
4. สร้าง Telegram bot โชว์สัญญาณล่าสุด 10 รายการ
5. รันเองดู 1 สัปดาห์ เช็คความแม่นยำแบบ paper trade ก่อนขาย
6. ถ้าความแม่นยำโอเค (55–60% ก็มีค่าแล้วในฐานะ sentiment overlay) เปิดกลุ่มฟรีให้ trader Twitter ไทย 20 คน
7. หลัง 2 สัปดาห์ให้ฟรี เปิด premium tier ราคา founder ฿1,500/เดือนสำหรับ 10 คนแรก
8. โพสต์สรุปสัญญาณรายวันบน Twitter ไทยเป็น organic growth

**เวลาจนได้ลูกค้าคนแรก:** 3–5 สัปดาห์ (ต้องสร้างความน่าเชื่อถือก่อน)
**ความเสี่ยงหลัก:** ความเสี่ยงสูงสุดในลิสต์นี้ — ถ้าสัญญาณแม่นยำต่ำ โปรดักต์ไร้ค่า ต้อง**ไม่การันตีผลตอบแทน**และบอกความแม่นยำจริงตรงๆ เสมอ

## 5. Thai E-Commerce Seller Toolkit

**ตรงกันทั้งคู่** — agy เสนอ "Shopee/Lazada Video Ad Generator", zcode เสนอ "E-Commerce Competitor Intel Dashboard" — สองมุมของปัญหาเดียวกัน (แม่ค้าออนไลน์ไทย)

**เหมาะกับ:** แม่ค้า Shopee/Lazada/TikTok Shop, dropshipper ไทย, เอเจนซี่ที่ดูแลผู้ขายหลายเจ้า
**คนจ่ายเงิน:** แม่ค้าที่อยากได้วิดีโอโฆษณาเร็วๆ หรืออยากรู้ว่าคู่แข่งทำอะไรอยู่

**โมเดลรายได้:**
- โมดูลวิดีโอโฆษณา: Credit pack ฿590/10 คลิป, ฿1,490/30 คลิป
- โมดูลสอดแนมคู่แข่ง: ฿1,990/เดือน/ร้าน (3 คู่แข่ง), ฿4,900/เดือน agency tier (10 คู่แข่ง + white-label report)

**Tool stack (วิดีโอโฆษณา):** `firecrawl.dev` (scrape หน้าสินค้า) → `deepseek.com` (เขียนสคริปต์ Hook-Problem-Solution-CTA) → `speechgen.io` (พากย์) → `creatomate.com` (render)
**Tool stack (สอดแนมคู่แข่ง):** `apify.com` (scrape Shopee/Lazada actor) → `openrouter.ai` (สรุปการเปลี่ยนแปลงรายวันเป็นไทย) → `railway.com` + Telegram bot

**ขั้นตอน MVP (เริ่มจากวิดีโอโฆษณา — ปิดขายง่ายกว่า):**
1. ทำฟอร์มรับลิงก์สินค้า Shopee/Lazada (LINE หรือเว็บง่ายๆ)
2. Firecrawl ดึงชื่อ, จุดเด่น, ราคา, รีวิว, รูปสินค้า
3. DeepSeek เขียนสคริปต์โฆษณาไทย 30 วิ (Hook → ปัญหา → ทางแก้ → CTA)
4. Speechgen สร้างเสียงพากย์
5. Creatomate ต่อรูป+สคริปต์+เสียงเป็นวิดีโอ 9:16 ด้วย template สำเร็จรูป
6. ส่งวิดีโอกลับทาง LINE/อีเมลภายใน 3 นาที
7. DM ผู้ขาย TikTok Shop ไทย 50 คน เสนอทำวิดีโอตัวอย่างฟรี 1 ชิ้นจากสินค้าขายดี
8. ปิดลูกค้าจ่ายเงิน 3 คนแรกที่แพ็ก ฿590

**เวลาจนได้ลูกค้าคนแรก:** 2 สัปดาห์
**ความเสี่ยงหลัก:** Shopee/Lazada เปลี่ยนโครงสร้างเว็บทำให้ scraper พัง — ต้องมี fallback scraping วิธีสำรอง 1 ตัวเสมอ

## 6. Thai Brand & Social Sentiment Alert

**เสนอโดย agy เพียงตัวเดียว** (ไม่มี convergence แต่ยังน่าสนใจ)

**เหมาะกับ:** แบรนด์อีคอมเมิร์ซไทย, เอเจนซี่ PR
**คนจ่ายเงิน:** แบรนด์ที่กลัวโดน "ดราม่า" บนโซเชียลแล้วรู้ตัวช้า

**โมเดลรายได้:** ฿1,490/เดือน/แบรนด์ที่มอนิเตอร์

**Tool stack:** `twitterapi.io` + `apify.com` (สแกน X/Pantip) → `mistral.ai`/`openrouter.ai` (จัดหมวด sentiment: ปกติ/บวก/ร้องเรียนด่วน/วิกฤต) → `railway.com` (cron + LINE Notify)

**ขั้นตอน MVP:**
1. Cron engine บน Railway query twitterapi.io ทุก 15 นาทีหาชื่อแบรนด์/hashtag
2. เสริม apify.com scrape กระทู้ Pantip
3. ส่งโพสต์เข้า Mistral/OpenRouter จัดหมวด sentiment ไทย
4. ถ้าเจอ "ร้องเรียนด่วน"/"วิกฤต" ส่ง LINE Notify ทันทีพร้อมลิงก์โพสต์ + คำแนะนำตอบกลับที่ AI ร่างให้
5. สรุปรายวัน 9 โมงเช้า พร้อมกราฟ sentiment
6. ทัก 20 เจ้าของแบรนด์/เอเจนซี่ PR เสนอ trial 14 วันมอนิเตอร์แบรนด์ตัวเอง+คู่แข่ง
7. ปิดลูกค้า 2 รายแรกที่ ฿1,490/เดือน

**เวลาจนได้ลูกค้าคนแรก:** 3–4 สัปดาห์
**ความเสี่ยงหลัก:** ค่า API พุ่งถ้า track คำกว้างเกินไป — ต้อง filter keyword ให้แคบและเฉพาะเจาะจง
