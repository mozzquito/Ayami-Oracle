## Lessons Learned

- **Treat IP addresses/numbers read off a photographed or scanned diagram as low-confidence until
  cross-checked against an authoritative source** (firewall config, VPN console, DNS record) —
  digit transposition (e.g. 163↔183) is a predictable failure mode with dense technical diagrams,
  and the first mention of such a number should be hedged, not asserted.

- **When asked to "block public access without breaking an integration," default to L7
  (application/WAF, path- or header-aware) mechanisms over L3/L4 (network firewall) blocking** —
  network-layer blocking can't distinguish traffic sharing the same domain/IP by purpose (UI vs
  API), so any requirement to selectively preserve one path invalidates a network-layer plan.

- **For a public self-service portal, per-account disable is not a valid "close the whole site"
  mechanism** — it doesn't scale to the user base and doesn't stop new signups; a "shut off
  public access" requirement needs a bulk/global toggle (app maintenance flag or L7 rule), which
  operates at a structurally different layer than individual account suspension.
