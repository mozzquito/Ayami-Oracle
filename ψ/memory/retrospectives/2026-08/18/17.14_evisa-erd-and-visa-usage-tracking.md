## Lessons Learned

1. **A claim like "X was not found" is only as strong as the searches that produced it — state
   what was actually searched, not that the thing doesn't exist.** "Checked against every search
   run so far" is a true but weaker claim than it reads; if a diagram or document will present an
   absence as a fact, run one targeted search for the exact term first, or phrase the claim as
   "no confirmed match yet" rather than "not found."
2. **When a request implies "is this recorded anywhere in this system," check the fullest
   available list of that system's own internal states/stages (status master tables, workflow
   definitions) before answering from architectural reasoning alone.** Reasoning about system
   boundaries ("this belongs to a different agency") is a good hypothesis but not a substitute for
   checking the system's own enumerated states when that check is cheap and available.
