## Lessons Learned

- When a user has just confirmed they want to be asked about repo-shape decisions (location, content scope), fold *every* naming/identity decision — including the repo name itself — into that same confirmation round rather than deciding it unilaterally afterward, even when the choice is low-risk and matches an existing convention.
- Before delegating a design-review question to a sibling agent (zcode/agy) per the SDLC-gate mandate, do the cheap local verification first (check existing config files, prior art in the repo) so the sibling agent's critique has concrete state to react to instead of having to guess at the project's current setup.
- When multiple Claude Code sessions are plausibly running against the same project directory, check the scratchpad path embedded in the system prompt for the true session ID *before* trusting `ls -t` on the project's `.jsonl` directory — it's a more reliable disambiguator than any timestamp-based heuristic on the directory listing.
