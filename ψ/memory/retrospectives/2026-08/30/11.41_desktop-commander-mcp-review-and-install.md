## Lessons Learned

- **ก่อน health-check MCP server ตัวใหม่ที่ติดตั้งผ่าน npx ให้ pre-fetch package ด้วยคำสั่งตรงๆ ก่อนเสมอ** เพราะรอบแรกมักช้ากว่า timeout ของ health check (มักอยู่ที่ ~30s) จาก cold npm download — pre-fetch แยกออกมาก่อนช่วยแยกปัญหา "ยังไม่ cache" ออกจากปัญหา "config ผิด" ได้ทันทีโดยไม่ต้องเดา
- **บน macOS ห้ามสมมติว่า `timeout` command มีอยู่** — เป็น GNU coreutils ไม่ใช่ BSD default, ให้ใช้ `gtimeout` (ถ้ามี brew coreutils) หรือใช้ tool-level timeout parameter (เช่น Bash tool's `timeout` field) แทนการ wrap คำสั่งด้วย `timeout` เปล่าๆ
- **เมื่อ user ขอให้ "ช่วยดูความเหมาะสม" ของเนื้อหาที่จะเผยแพร่ ให้ตรวจ source ต้นทาง ไม่ใช่แค่เช็คว่า claim ฟังดูสมเหตุสมผล** — จุดที่มีมูลค่าที่สุดมักเป็นสิ่งที่ร่างไม่ได้พูดถึงเลย (เช่น telemetry/sandbox ในเคสนี้) ไม่ใช่แค่ยืนยันว่าสิ่งที่เขียนไว้ถูกหรือผิด
