## Lessons Learned

- **ก่อน delegate งานที่ไม่ใช่ text-in-text-out (audio, image, binary format) ไปให้ agent อื่น ให้เช็คก่อนว่า agent นั้นรองรับ input ประเภทนั้นจริงไหม** — ถ้าไม่ชัด ให้ทดสอบเล็กๆ ก่อน หรือเช็ค local capability (installed tools) ก่อนเสมอ จะได้ไม่เสียเวลาไปกับ agent ที่ไปเลือกทางแก้ของมันเอง (เช่น ดาวน์โหลด model ทั้งลูก) แบบควบคุมไม่ได้
- **เมื่อ multimodal input (รูปภาพ) ถูกส่งมาในบทสนทนาอยู่แล้ว และตัวเองมี vision capability ตรงๆ ไม่จำเป็นต้อง route ผ่าน agent อื่นตามคำขอเสมอไป** — เลือกเครื่องมือที่ตรงกับงานที่สุด แล้วอธิบายเหตุผลให้ user เข้าใจว่าทำไมไม่ทำตามที่สั่งตรงตัว (transparency ยังคงอยู่)
- **เมื่อไฟล์อ่านไม่ได้ (unzip/read ค้างหรือ error แปลกๆ) ให้เช็ค process list (`ps aux`) หา background sync process (iCloud `bird`, Dropbox, OneDrive ฯลฯ) เป็นหนึ่งในสมมติฐานแรกๆ ก่อนสงสัยว่าไฟล์เสีย** — โดยเฉพาะไฟล์ใน `~/Documents`, `~/Desktop` ที่มักถูก cloud-sync แบบ optimize storage
- **เมื่อ output คุณภาพต่ำ (เช่น STT hallucination, garbled OCR) ให้รายงานขอบเขตความไม่แน่นอนตรงๆ พร้อมชี้จุดที่ใช้ได้/ใช้ไม่ได้ แทนที่จะส่งของทั้งดุ้นหรือเนียนสรุปให้ดูสมบูรณ์กว่าที่เป็นจริง** — ความน่าเชื่อถือสำคัญกว่าความประทับใจ
