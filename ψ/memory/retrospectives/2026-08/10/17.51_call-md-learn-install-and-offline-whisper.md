## Lessons Learned

- **For small, boundedscope exploration tasks (read ~3-5 known files, summarize), doing it directly beats spawning a subagent and waiting** — subagent overhead (spin-up + unpredictable latency) can exceed the task itself; reserve delegation for tasks that are actually large, parallel, or context-heavy.
- **Never trust a CLI agent's self-reported "I successfully processed X" claim about a capability it wasn't built for (e.g., a text-only coding agent claiming to analyze video/audio) — verify against independent ground truth (`ffprobe`, a checksum, an actual re-run) before repeating the claim to the user.**
- **When an app UI shows "nothing happened" after an action, check the app's own persisted state (DB, config files) directly before asking the user to describe more UI symptoms — it's often faster and more conclusive than round-tripping through their description of what they saw.**
- **A `sudo`-run package-manager command can silently corrupt that manager's cache for all future non-sudo use — when any `npx`/`pip`/`npm` command fails with unexplained `EACCES`, check for root-owned files in the relevant cache dir before assuming the failure is project-specific.**
