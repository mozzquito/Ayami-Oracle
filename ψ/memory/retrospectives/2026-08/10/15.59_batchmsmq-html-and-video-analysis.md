## Lessons Learned

- **เมื่อโจทย์คือ "แปลง diagram file (drawio/XML) เป็น HTML" และ diagram มีความหมายเชิงโครงสร้าง (sequence/architecture) ไม่ใช่แค่รูปภาพ ให้แกะข้อมูลจริงจากไฟล์มาเรนเดอร์เอง (SVG/data-driven) แทนการฝัง viewer ภายนอกหรือแปะ screenshot** — ได้ผลลัพธ์ที่ตรงต้นฉบับกว่า, แก้ไข/scale ได้, และไม่ชนข้อจำกัดของ CSP ในสภาพแวดล้อมที่ block external resource
- **บทเรียนเรื่อง "เช็ค local capability ก่อน delegate" (จาก retro เมื่อเช้าเซสชันเดียวกัน) ใช้ได้ผลจริงเมื่อนำมาปรับใช้ทันที** — ยืนยันว่า pattern ที่บันทึกไว้ใน `ψ/memory/learnings/` มีค่าจริงเมื่อดึงมาใช้ในสถานการณ์คล้ายกันครั้งถัดไปในเซสชันเดียวกัน ไม่ต้องรอเซสชันใหม่
- **เมื่อ transcript/OCR/extraction มีคุณภาพไม่สม่ำเสมอ (บางช่วงดี บางช่วงพัง) ให้ระบุขอบเขตที่ใช้ได้อย่างเจาะจง (นาทีที่เท่าไหร่ถึงเท่าไหร่) แทนคำกว้างๆ อย่าง "ถอดได้เกือบหมด"** — ให้ user ประเมินเองได้ว่าเนื้อหาที่ขาดหายสำคัญแค่ไหน
