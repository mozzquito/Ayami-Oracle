## Lessons Learned

- When live-dictated notes introduce an ambiguous new term that might overlap with something already noted, keep it as its own separate line item until the user explicitly confirms equivalence — don't fold it into an existing concept just because later content seems to describe the same feature. Silent merges during fast dictation cost the user a correction they have to make while distracted.
- The `/rrr` dig-miner "run `ls -t` in the main agent's own shell instead of the subagent's" fix does not actually close the wrong-session-file bug — `ls -t` is vulnerable regardless of which process calls it, because it's ranking *all* concurrently-active session files in the project directory by mtime, not just this session's. A content-based fallback (grep the project dir's `.jsonl` files for a distinctive phrase known to be unique to this conversation) is the reliable disambiguator when multiple sessions are running concurrently against the same project.
- Before offering to build a credential-swapping script for OAuth-based CLI multi-account use, check whether a vetted third-party tool already solves exactly that problem safely — reimplementing Keychain credential swaps from scratch means handling plaintext OAuth tokens directly, which is a real security regression compared to pointing the user at an existing, purpose-built tool.
