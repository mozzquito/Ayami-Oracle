## Lessons Learned

- เมื่อเครื่องมีหลาย network interface/subnet และผู้ใช้พูดกำกวมว่า "วง LAN" (ไม่ระบุ subnet) ให้เช็ค default route ก่อนเพื่อหาวงหลักที่เกตเวย์ใช้จริง แต่ถ้ามีมากกว่าหนึ่งวงที่สมเหตุสมผล (เช่น ทั้งคู่มี gateway) ควรแจ้งตัวเลือกให้ผู้ใช้ยืนยันก่อน scan แทนที่จะเลือกให้เองเงียบๆ — ป้องกันการ scan ผิดวงในบริบทที่มี VPN/dual-NIC ตั้งใจ
