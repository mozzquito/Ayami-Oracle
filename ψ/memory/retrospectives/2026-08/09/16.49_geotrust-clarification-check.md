## Lessons Learned

- **Before answering an out-of-context question that might belong to a sibling concurrent session, do a quick active check of shared state (vault grep, memory search) rather than relying only on what's already sitting in your own recall** — recall-based inference can happen to be right, but an active check turns "probably" into "confirmed" for the same cost of a few seconds, and shared state (like a memory/vault system) is specifically there to bridge exactly this kind of cross-session gap.
