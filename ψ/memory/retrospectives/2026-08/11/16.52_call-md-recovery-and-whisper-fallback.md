## Lessons Learned

- **เมื่อเจอ ASR/transcript แปลกๆ (ปนภาษาไม่มีความหมาย) ให้ตรวจสอบคุณภาพก่อนสรุป ไม่ใช่พยายามตีความจากข้อมูลที่ดูผิดปกติ** — สัญญาณ garbled multilingual text มักแปลว่า pipeline พัง (เช่น รับ noise/background audio) ไม่ใช่เนื้อหาจริง
- **แอป desktop (Electron) มักเก็บ state จริงใน SQLite ใต้ `~/Library/Application Support/<app>/`, ไม่ใช่ path export/config ที่ผู้ใช้คุ้นเคย** — เมื่อ path ที่คาดไว้ไม่มีจริง ให้มองหา app's own local database ก่อนที่จะยอมแพ้
- **เมื่อ automated pipeline (แอป) ถอดเสียงพัง ให้ retrieve raw media (stream URL / audio file) แล้ว fallback ไปใช้เครื่องมือ transcribe ที่ควบคุมได้เอง (เช่น local whisper) แทนที่จะพึ่งผลจากระบบเดิม**
- **scope การค้นหาไฟล์ให้แคบที่สุดเท่าที่รู้จาก context ก่อนเสมอ** — recursive full-home grep เป็นทางเลือกสุดท้าย ไม่ใช่ทางแรก
- **ผลจาก dig-miner/session-detection ที่อิงแค่ mtime (`ls -t *.jsonl | head -1`) ต้อง sanity-check กับเนื้อหาจริงในบทสนทนาก่อนเชื่อเสมอ** — ถ้ามีข้อความที่ไม่คุ้นเลย (ชื่อโปรเจกต์/หัวข้อไม่เคยพูดถึง) ให้สงสัยว่าหยิบ session ผิดทันที แล้ว fallback ไป reconstruct จาก conversation memory พร้อม label ว่าเป็น approximate — อย่า merge ข้อมูลที่ไม่ sanity-check แล้วเข้า timeline
