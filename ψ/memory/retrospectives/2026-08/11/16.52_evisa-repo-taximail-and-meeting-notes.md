## Lessons Learned

- **เมื่อทำข้อตกลงเรื่องขอบเขต PII กับ user ไปแล้วครั้งหนึ่งในเซสชัน (เช่น ไม่เก็บบัตรประชาชน) ให้ generalize มาตรฐานนั้นไปใช้กับข้อมูลส่วนบุคคลรูปแบบอื่นที่โผล่มาทีหลังโดยอัตโนมัติ (อีเมล, ชื่อบุคคลที่สามใน log/screenshot) ไม่ใช่รอให้ระบบ/คนอื่นทักก่อน** — precedent ที่ตกลงไปแล้วควรเป็นกฎที่ apply ทั่วทั้งเซสชัน ไม่ใช่กฎเฉพาะไฟล์แรกที่คุยกัน
- **เมื่อ generic skill (เช่น `/learn`) ถูกเรียกกับ target ที่ไม่ตรงกับ mechanic ที่ออกแบบไว้ (เช่น โฟลเดอร์เอกสารแทน git repo) ให้แยกเจตนาของสกิลออกจากกลไกเฉพาะของมัน แล้วเลือกเครื่องมือที่เหมาะกับ target จริง แทนการ force-fit หรือปฏิเสธที่จะทำ** — ทั้งสองทางสุดขั้วเสียโอกาส ทางกลางที่ปรับ tool ให้เข้ากับ intent ได้ผลลัพธ์ที่มีประโยชน์กว่า
- **เอกสาร docx/pptx ที่ text extraction ได้เนื้อหาน้อยผิดปกติ ให้เช็คจำนวนภาพฝัง (`unzip -l file.docx | grep -c media/`) ก่อนสรุปว่าเอกสารไม่มีเนื้อหา** — คู่มือ step-by-step จำนวนมากเป็น screenshot-driven ข้อความมีน้อยหรือไม่มีเลย ต้องอ่านภาพด้วย vision ถึงจะได้เนื้อหาจริง
- **Background subagent ที่ auto-detect session file ด้วย `ls -t` ไม่น่าเชื่อถือเมื่อมีหลาย session ทำงานคู่ขนานในโปรเจคเดียวกัน — ควรส่ง session ID ที่ detect ไว้แล้วแบบ literal ให้ subagent ใช้ตรงๆ แทนที่จะให้มันค้นหาเอง**
