## Lessons Learned

- **Typecheck passing is necessary but not sufficient verification for React code** — it will never catch a Rules-of-Hooks violation (conditional hook calls, hooks after early returns), since that's a runtime contract, not a type. When reviewing a delegated diff that touches component bodies with early returns, explicitly scan for "is every hook call above every return statement" as a separate manual check, every time — don't fold it into "typecheck passed, done."
- **Never embed markdown backtick-code-formatting inside a double-quoted shell argument** when constructing a prompt for a CLI tool invoked via Bash — write the prompt to a file first (heredoc with a quoted delimiter) and pass it via command substitution, or strip backtick formatting from inline identifiers, whenever the prompt text itself contains code-like syntax with parentheses.
- **When an external delegate agent hits a hard quota/rate-limit mid-task and produces no coherent final report, treat the diff as fully unverified** — don't extrapolate partial credit from a garbled error dump. The correct response is a full from-scratch diff review, same rigor as if the agent had claimed total success.
- **A user's simple follow-up question is a legitimate trigger to re-verify a claim you already made**, not just to answer from memory of what you said before — the AI summary question here surfaced a bigger, previously-undetected bug specifically because the answer required re-tracing the actual data flow instead of restating the earlier (incomplete) assessment.
