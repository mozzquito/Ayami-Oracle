## Lessons Learned

1. **เมื่อ delegate ให้ autonomous agent (zcode/agy) ที่รันอยู่ใน repo ที่มี CLAUDE.md เป็นของตัวเอง ให้ใส่ `--sandbox`/`--disallowedTools` เป็นค่าเริ่มต้นเสมอสำหรับงาน brainstorm/analyze ล้วนๆ** — ไม่งั้น agent จะพยายามทำตาม convention ของ repo (เช่น session-activity logging) แล้ว fail แบบ non-obvious ในโหมด background ที่ตอบ permission prompt ไม่ได้ ใส่ให้ทั้งสอง agent เท่ากันตั้งแต่ call แรก อย่าใส่ให้ตัวเดียว
2. **งาน "เช็ค N ลิงก์สดแล้วประเมิน" ควรใช้ parallel fork + WebFetch แทน browser automation เต็มรูปแบบ** — เร็วกว่ามาก ไม่มี race condition จาก shared browser tab ระหว่าง agent หลายตัว และแต่ละ fork สรุปให้กระชับก่อนส่งกลับ ทำให้ context หลักไม่บวมจาก raw page dump
3. **เมื่อ agent อิสระสองตัว (คนละ model, ไม่เห็นคำตอบกัน) เสนอไอเดีย/ข้อสรุปแบบเดียวกันเอง ให้ถือเป็นสัญญาณความน่าเชื่อถือและบอก user ตรงๆ** (เช่น badge "ตรงกันทั้งคู่") — เป็น cross-validation ที่ถูกและได้ผลจริง ควรใช้ทุกครั้งที่ delegate งานประเภทเดียวกันให้สอง agent พร้อมกัน
4. **เมื่อโจทย์กว้างแบบ "คิดไอเดียให้หน่อย" โดยไม่ระบุว่าผูกกับโปรเจคที่มีอยู่หรือไม่ ให้ถามหรือระบุ assumption ไว้ล่วงหน้า** ก่อนรัน multi-agent brainstorm ที่มีต้นทุนสูง (หลาย background call) — ลด risk ที่ต้องรันซ้ำทั้งหมดเพราะตีความ scope ผิด
