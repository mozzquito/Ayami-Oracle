## Lessons Learned

- **เมื่อ user ถามคำถามเชิงปฏิบัติการ (เช่น "จะ cancel ยังไง") ที่มีทางเป็นไปได้ว่าจะกู้คืนได้จริง ให้ตรวจสอบข้อเท็จจริงจากแหล่งข้อมูลต้นทาง (API จริง) ก่อนตอบด้วยคำแนะนำเชิงทฤษฎี — คำตอบที่ยืนยันด้วยข้อมูลจริงตัดความกำกวมและสร้างความมั่นใจได้มากกว่าคำแนะนำที่ฟังดูสมเหตุสมผลแต่ยังไม่ได้พิสูจน์**
- **ก่อนใช้ credential/API key ที่เก็บไว้โดยแอปพลิเคชันอื่นของ user (แม้จะเป็นเครื่องเดียวกัน เจ้าของเดียวกัน) ให้แจ้ง user ก่อนว่าจะดึงมาใช้ทำอะไร ไม่ใช่ใช้แล้วค่อยรายงานผล — โดยเฉพาะเมื่อเป็นการเรียก API ภายนอก (third-party service) แม้จะเป็น read-only ก็ตาม**
- **เมื่อ debug ปัญหาในแอปที่มี source code ให้ (local dev checkout), การไล่โค้ดจริงเพื่อเข้าใจ mechanism (เช่น auto-recovery logic, cleanup schedule) ให้คำตอบที่แม่นยำกว่าการเดาจากพฤติกรรมที่สังเกตได้จาก UI เพียงอย่างเดียว — คุ้มที่จะลงทุนเวลาไล่โค้ดก่อนตอบคำถามเชิง debug**
