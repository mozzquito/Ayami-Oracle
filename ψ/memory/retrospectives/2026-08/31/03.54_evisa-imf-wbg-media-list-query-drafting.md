## Lessons Learned

1. **SQL Server schema-export scripts (จาก SSMS "Generate Scripts") มักเป็น UTF-16LE — grep/cat ตรงๆ
   จะไม่เจออะไรเลยแม้เนื้อหาจะมีอยู่จริง** ต้อง `iconv -f UTF-16LE -t UTF-8` แปลงก่อนเสมอ ถ้า grep
   ไม่เจอสิ่งที่มั่นใจว่าต้องมี (เช่น table ที่ user เพิ่งพูดชื่อมาเป๊ะๆ) ให้สงสัย encoding ก่อนสรุปว่า
   "ไม่มีตารางนี้ในระบบ"

2. **ก่อนเริ่มร่าง SQL ใหม่จากศูนย์สำหรับ report/query ประเภทเดิม ให้ถาม (หรือค้นความจำของตัวเอง) ว่า
   "เคยมี query/view สำเร็จรูปสำหรับเรื่องนี้อยู่แล้วหรือยัง" ก่อนเสมอ** — โดยเฉพาะถ้าเคยบันทึก lesson
   แบบนี้ไว้แล้วในโปรเจกต์เดียวกัน (`2026-08-18_evisa-oracle-backoffice-schema-mapping.md`) แต่ไม่ได้
   นำมาใช้ตอนเริ่มงานจริง — บันทึกความรู้ไว้เฉยๆ ไม่มีประโยชน์ถ้าไม่ถูกเรียกใช้ก่อนเริ่มงานใหม่ที่ตรงกัน

3. **ไฟล์ data export/CSV ขนาดใหญ่ (>50-100MB) ควรเช็คขนาดด้วย `ls -la`/`du -sh` ก่อน grep เสมอ** —
   grep ตรงๆ บนไฟล์หลักร้อย MB มักจะชน timeout 120s ของ background bash โดยไม่ได้ผลลัพธ์อะไรกลับมา
   เสียเวลาไปฟรี เทียบกับเช็คขนาดก่อนแล้วเลือก scope การค้นหาให้แคบลง (เช่น เฉพาะไฟล์ schema-only)
