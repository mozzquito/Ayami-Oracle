## Lessons Learned

1. **`/learn` เจอ URL ที่ไม่ใช่ GitHub repo → ข้าม ghq-clone flow ทันที ไม่ต้องพยายามยัดเข้า flow เดิม**
   ใช้ WebFetch (หรือ Playwright ถ้าโดนบล็อก) ดึงเนื้อหาตรง สรุป แล้วบันทึกเป็น `ψ/memory/learnings/` แบบ
   เดียวกับ Trace Connection pattern — ไม่ต้อง `ghq get`/symlink `origin/`/สร้าง hub file เพราะไม่มี codebase
   ให้สำรวจ กฎ generalizable: **สกิลที่เขียนมาสำหรับ "codebase" ควรถูกตรวจสอบ URL-type ก่อนทุกครั้ง ก่อนเข้า
   flow เฉพาะของมัน**

2. **URL ที่ผู้ใช้ paste มาซึ่งมีสัญญาณตัดทอน (`...`, `…`, หรือความยาวผิดปกติ) ให้สงสัยก่อน fetch เสมอ** — ยิง
   ตรงๆ ครั้งแรกถ้าพลาดก็แค่เสีย 1 round-trip แต่ถ้ารู้ตั้งแต่แรกว่ามีสัญญาณตัดทอนควรข้ามไป fetch หน้า index/
   ค้นหาแทนตั้งแต่ต้น ประหยัดกว่า

3. **เมื่อ user มอบอำนาจ "install ถ้ามีประโยชน์" ให้เครื่องมือ/tool ภายนอก ให้แยกระดับความหนักของสิ่งที่จะ
   ติดตั้งก่อนตัดสินใจเอง**: markdown skill (git-tracked, reversible, ไม่มี external call) → ตัดสินใจเองได้
   เลยถ้าผ่าน security checklist; infrastructure จริง (binary download, background server, external service
   integration) → ต้องกลับไปถามแม้ user จะพูดคำว่า "install ได้เลย" ไว้ก่อนแล้ว เพราะ scope ของ "ติดตั้งได้เลย"
   ไม่ควรครอบคลุมถึงการดาวน์โหลดไฟล์ไบนารีหรือสร้าง integration ใหม่โดยอัตโนมัติ
