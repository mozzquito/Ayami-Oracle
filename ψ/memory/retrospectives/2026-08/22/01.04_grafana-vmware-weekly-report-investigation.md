## Lessons Learned

1. **Never write a specific "likely cause" into a client-facing artifact from a coarse-resolution chart image alone.** A 5-minute-bucketed graph can visually disguise a real sustained multi-minute event as a single spike. Query the underlying time series at native/fine resolution *before* writing any causal hypothesis into a document meant to inform real decisions — a coarse screenshot is fine for "something happened here," never for "here's probably why."

2. **A confirmed root cause for one host/metric does not transfer to a different host/metric just because they're in the same report and "feel similar."** Chronic, sustained anomalies (elevated nearly continuously) and one-off time-boxed incidents are different failure classes and usually have different causes even within the same infrastructure — check the second case's own data before reusing the first case's explanation, no matter how tempting the pattern-match is.

3. **When a user pastes live credentials in plaintext chat, use them for the explicit task at hand but proactively flag the exposure and recommend rotation in the same turn** — don't wait to be asked, and don't silently proceed as if it were unremarkable.
