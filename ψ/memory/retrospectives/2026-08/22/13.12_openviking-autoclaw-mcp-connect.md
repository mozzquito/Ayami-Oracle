## Lessons Learned

1. **Grep for secret-shaped keys before the first full read of any unfamiliar app's config or state file.** Search for `token|key|secret|authorization|bearer|jwt|password` first; only dump full contents once that comes back clean. Applies to any local-machine audit of third-party app config, not just this session.
2. **A pasted URL with ad-tracking query params (`gclid`, `gad_source`, `gad_campaignid`) is a strong signal to pause and confirm intent before treating it as a deliverable target** (repo to clone, page to scrape as primary source) — it usually means the link was copied mid-click, not deliberately chosen.
3. **When delegating a security-sensitive directory review to a separate CLI agent, pass an explicit file/path exclusion list rather than trusting the agent to infer sensitivity on its own.** Both zcode and agy respected an explicit list correctly in this session; an implicit "be careful" instruction would have been weaker.
4. **Before wiring a new MCP server into a session, probe its live state first** (auth status of any account connectors, full tool list, whether writes are gated) rather than reasoning from documentation alone — the actual blast radius here turned out much smaller than the app's own security profile suggested, because nothing was authenticated yet.
