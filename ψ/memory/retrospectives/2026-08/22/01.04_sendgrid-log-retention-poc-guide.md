## Lessons Learned

- When AskUserQuestion is rejected, don't re-ask a reshaped version of the same question — proceed on the single fact the user volunteers next and treat everything else as an inferred default, stated inline so it's easy to correct. Rejection is itself an answer ("stop blocking, keep going"), not a request for a better-designed question.
- Adapting a repo-exploration skill (`/learn`) to a non-repo input (a docs URL) by substituting the read step (WebFetch/WebSearch instead of `ghq clone`) while keeping the rest of the skill's intent (produce a saved learning doc, log to `ψ/memory/learnings`) is the right move when a skill's literal mechanism doesn't fit but its purpose clearly does.
- A per-stage sibling-agent consult (zcode/agy) that fails on the *first* attempt for an environment/permission reason (not a task reason) should not be retried identically a second time — either try a variant that avoids the failing side-effect, or disclose the skip and move on; two identical failing retries burn a turn for zero new information.
