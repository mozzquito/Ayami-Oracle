2. **ไม่มี DB client ต่อ MSSQL ได้ในเครื่องนี้ (ปัญหาเดิมที่เคยบันทึกไว้)** — ทุก query ต้องส่งมอบเป็น text ให้มอสไปรันเองใน SSMS แล้ว paste ผลกลับมา วนซ้ำ pattern เดิมจาก session ก่อนหน้า (2026-08-27) ยังไม่ได้แก้ root cause
3. **มอส interrupt tool call กลางคัน** — เป็นสัญญาณตรงว่าทิศทางที่ทำอยู่ผิด แต่กว่าจะรู้ตัวคือหลังจากทำงานไปแล้วหลายขั้นตอน (convert, transcribe, volumedetect, normalize) ถ้าถามยืนยันประเภทเนื้อหาตั้งแต่ต้น (หรือเช็คเฟรมก่อน) จะไม่ต้องให้มอสต้อง interrupt เอง

## Lessons Learned

1. **ก่อนรัน pipeline หนักๆ ประเภทเดียว (audio-only หรือ vision-only) กับไฟล์วิดีโอ ให้เช็คถูกด้วยการดูตัวอย่างเบาๆ ก่อนเสมอ** — เช่น extract 1 เฟรมมาดู หรือ `ffprobe` เช็ค stream ว่ามีเสียงพูดจริงไหม แทนที่จะเดา modality จากคำสั่งที่กำกวม (เช่นคำว่า "ภาษา" ในภาษาไทยที่กำกวมระหว่างพูด/เขียน) การเช็คแบบเบาก่อนถูกกว่าการรัน pipeline เต็มแล้วพบว่าผิดประเภท
2. **เมื่อ DB column เป็น Always Encrypted (หรือถูกป้องกันด้วยกลไกคล้ายกัน) ห้าม filter บนคอลัมน์นั้นตรงๆ — ต้อง route ผ่าน field ที่ไม่เข้ารหัสที่ correlate กันแทนเสมอ** และค่าที่ต้องใช้ join/filter (เช่น country code) ต้อง verify กับ master table หรือ schema ที่บันทึกไว้จริง ไม่เดาแม้จะทำให้ query ดูสมบูรณ์กว่า — ยิ่งข้อมูลเป็น PII/regulated system ยิ่งต้องเข้มงวดกับกฎนี้
