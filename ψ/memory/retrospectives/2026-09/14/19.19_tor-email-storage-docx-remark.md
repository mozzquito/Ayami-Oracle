## Lessons Learned

- เมื่อ sandbox ปฏิเสธการเขียนไฟล์ที่ `/tmp` โดยตรง (read-only filesystem) ให้ใช้ scratchpad directory ที่ระบุไว้ใน system prompt ของ session นั้นแทนเสมอ อย่าพยายาม retry `/tmp` ซ้ำ
- เมื่อไม่มี pandoc สำหรับแปลง docx บน macOS ให้ใช้ `textutil -convert txt -stdout <file>` (built-in) สำหรับอ่าน และ `uv run --with python-docx python3 script.py` สำหรับเขียน/แก้ไข docx แบบ ad-hoc โดยไม่ต้อง pollute global python env
- เมื่อแทรกเนื้อหาลงใน docx ด้วย python-docx ให้ list paragraph index ทั้งหมดก่อนเขียน insert script เสมอ (`insert_paragraph_before` ต้องรู้ตำแหน่ง anchor ที่แน่นอน) แล้ว verify ผลลัพธ์ด้วยการแปลงกลับเป็น text อีกรอบก่อนส่งมอบงาน — อย่า assert ว่าไฟล์ถูกต้องจากแค่ exit code ของ script
- เมื่อจะ annotate/remark เอกสารที่มีโอกาสส่งต่อให้บุคคลที่สามอ่าน (ไม่ใช่แค่ draft ภายใน) ควรถามสั้นๆ ก่อนว่าต้องการ Word track-changes/comment จริง หรือ inline text remark ก็พอ แทนที่จะเดาฟอร์แมตเอง
