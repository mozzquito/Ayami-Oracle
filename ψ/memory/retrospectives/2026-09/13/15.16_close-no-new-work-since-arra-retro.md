## Lessons Learned

- On any `/rrr` request, check for an existing recent retro on *this session's own ID* before
  drafting — `find $PSI/memory/retrospectives -newer <last-known-retro>` and grep each candidate's
  `📡 Session:` line is a cheap, mechanical way to do this before trusting conversation memory
  (which may not span a compaction boundary) or repo state (which spans every concurrent session).
- When a "close the session, nothing pending" request lands on a session that already has a recent
  retro, the retro to write is a *delta* (verified-empty or verified-small) against that prior
  retro's cutoff, not a fresh full narrative — write full retros for full sessions, delta retros
  for delta time windows.
- A repo shared by multiple concurrent Claude Code sessions makes `git log`/`git status`/`git diff`
  actively misleading as evidence for "what did *this* session do" — always cross-check against the
  session's own transcript (`.jsonl`, keyed by `$CLAUDE_SESSION_ID`) before treating repo state as
  session history.
