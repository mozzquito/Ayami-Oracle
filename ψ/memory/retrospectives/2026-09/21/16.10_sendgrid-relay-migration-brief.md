## Lessons Learned

1. **ต้องสร้าง commit เฉพาะไฟล์ในทรีที่ใช้ร่วมกับ session อื่นและสาขาแยกจาก origin: ใช้ worktree ชั่วคราวแตกจาก main แล้ว commit เฉพาะ path** อย่าสลับสาขาในทรีหลัก (ไฟล์ tracked อาจหายและงานค้างของ session อื่นถูกกระทบ) และอย่าเอา commit ไปต่อบนสาขาที่ประวัติแยก
2. **ไฟล์สถานะแบบ "เขียนทับ" (focus) อาจเป็นของ session อื่นที่ยังทำงานอยู่** ตรวจเนื้อหาก่อนเขียนทับ ถ้าเป็นงานอื่นให้ต่อท้าย log แทน
3. **คำรีวิวจากโมเดลอื่นต้องรันทดสอบเองกับโค้ดจริง** ตัวอย่างที่ให้ไปอาจผิดแม้แนวคิดถูก (agy: payload แบ่งครึ่งในเอกสารสั้นถูก flag ตามปกติ ต้องเป็นเอกสารยาวที่ตกรอยต่อ chunk)
4. **ข้อเท็จจริงของผู้ขายที่ยังไม่ได้ตรวจ ให้ติดป้ายแยกในเอกสารส่งมอบ** ไม่ปนกับข้อมูลที่ยืนยันแล้ว และเขียนว่าอะไรต้องตรวจก่อนสัญญากับลูกค้า
