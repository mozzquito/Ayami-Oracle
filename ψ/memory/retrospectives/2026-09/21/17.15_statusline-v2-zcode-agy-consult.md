## Lessons Learned
- Re-list exactly what a push will send (`git log origin/<branch>..HEAD`, `git diff --stat`) immediately before pushing to a shared or public remote, even when the user just approved it — approval covers the state they were shown, not the branch tip at push time.
- Never mutation-test (or otherwise deliberately break) a file that a live process executes on this machine — statuslines, hooks, cron scripts. Make the target path overridable via env var so tests run against a copy, especially when a tool timeout can background the run and leave the mutation live longer than intended.
- When delegating to an external read-only reviewer via a fanout/consult script, explicitly forbid network fetches in the prompt if the runtime can't grant that permission — an unexplained empty response is often a silently-denied tool call, not "nothing to say."
- A repo's visibility is a fact to look up per repo, not to remember from a prior session — `gh repo view OWNER/REPO` explicitly, since a bare `gh repo view` can resolve to a different default remote.
