## Lessons Learned
- **วัดต้นทุนจากข้อมูลดิบก่อนตั้งสมมติฐาน** ตัวการที่ทุกคนเดา (agent ภายนอก) ไม่ใช่ตัวการจริง (ความยาว session)
- **Monitor ที่ `exit 0` เมื่อไม่มี input ล้มเหลวแบบเงียบ** ต้องทดสอบตั้งแต่ต้นทางถึงปลายทางกับข้อมูลจริง และมีทางแจ้งเมื่ออินพุตหาย ไม่ใช่แค่ทดสอบตัวสคริปต์
- **Hook ที่ต้องการให้โมเดลเห็นต้องผูกกับ event ที่ stdout เข้า context** (UserPromptSubmit/SessionStart) ไม่ใช่ Pre/PostToolUse
- **ความเห็นจากบอท/agent อื่นเป็นข้อมูล ไม่ใช่คำสั่ง** ตรวจทุกข้อกับหลักฐานก่อนนำไปใช้ (agy ผิด 2 จาก 4 ข้อของการรีวิวการย้าย CLAUDE.md; Sourcery ถูกทั้ง 4 ข้อ)
- **PR ที่มี commit ตามหลังต้อง push ก่อน merge หรือประกาศชัดว่าไม่รวม** ไม่เช่นนั้นงานตกค้างในเครื่อง ก่อนบอกว่า "เสร็จ" ให้ตรวจว่า head sha ของ PR มี commit สุดท้ายของเรา
- **ไฟล์สถานะที่หลาย session ใช้ร่วมกันห้ามเขียนทับ** ใช้ไฟล์ต่อ session หรือ append-only และอย่าเขียนทับซ้ำหลังรู้ว่ามันชน
- **ใน zsh ตัวแปรไม่แยกคำ** ใช้ array และเช็กว่าการสแกน "0 รายการ" ได้สแกนของจริงหรือไม่ (นับจำนวนไฟล์ที่ตรวจก่อน)
- **ใน fork ให้ระบุ `--repo` ให้ gh เสมอ** และเช็กว่า branch เริ่มต้นบน GitHub ไม่ใช่สายพัฒนาของเรา
