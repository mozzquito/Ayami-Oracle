Monitor mode never drives the heater. Manual duty is a fixed, person-chosen SSR duty cycle for testing the switching path — not closed-loop temperature control. A hardware thermal cutoff independent of this board is required before using Manual duty with a live heater (see README.md).

Fill these in before each roast — they're written into every row of the CSV so a batch of logged roasts can later be grouped/compared by bean and roast level without a separate lookup file.
